Bootbox.js

Interactive examples for alert, confirm, prompt, custom dialogs — and the new LIFO dialog queue introduced in 6.1.0.

Running local dist/bootbox.all.js · v6.1.0

Dialog queue New in 6.1.0

By default only one Bootbox dialog is visible at a time. Opening another parks the current dialog; dismissing restores the previous one (LIFO).

Park & restore (LIFO)

New

Opens a first alert, then a second. The first is parked (hidden, state kept) until you dismiss the second — then it comes back. 

bootbox.alert({
  title: 'First dialog',
  message: 'I will be parked when the next dialog opens.'
});

bootbox.alert({
  title: 'Second dialog',
  message: 'Dismiss me to restore the first dialog.'
});

Dismiss all parked dialogs

New

bootbox.dismissAll() (alias of hideAll()) clears the active dialog and every parked dialog with no restore. 

bootbox.alert({ title: 'Layer 1', message: 'Parked first' });
bootbox.alert({ title: 'Layer 2', message: 'Parked second' });
bootbox.alert({ title: 'Layer 3', message: 'Active on top' });

// Later:
bootbox.dismissAll();

Legacy concurrent stacking

New

Pass queue: false (per dialog or via setDefaults) to restore the old Bootstrap stacking behavior. 

bootbox.alert({
  message: 'Bottom dialog',
  queue: false
});

bootbox.alert({
  message: 'Top dialog (both visible)',
  queue: false
});

Alert

Simple notifications with optional callbacks and sizing.

Basic usage

bootbox.alert('This is the default alert!');

With callback

bootbox.alert('This is an alert with a callback!', function () {
  console.log('This was logged in the callback!');
});

Small dialog

bootbox.alert({
  message: 'This is the small alert!',
  size: 'small'
});

Dismiss with overlay click

bootbox.alert({
  message: 'This alert can be dismissed by clicking on the background!',
  backdrop: true
});

Confirm

Yes/no decisions with custom button labels and colors.

Basic usage

bootbox.confirm('This is the default confirm!', function (result) {
  console.log('This was logged in the callback: ' + result);
});

Custom button text and color

bootbox.confirm({
  message: 'This is a confirm with custom button text and color! Do you like it?',
  buttons: {
    confirm: { label: 'Yes', className: 'btn-success' },
    cancel: { label: 'No', className: 'btn-danger' }
  },
  callback: function (result) {
    console.log('This was logged in the callback: ' + result);
  }
});

Prompt

Collect input with text, select, checkbox, and other HTML5 types.

Basic usage

bootbox.prompt('This is the default prompt!', function (result) {
  console.log(result);
});

Select input

bootbox.prompt({
  title: 'This is a prompt with select!',
  inputType: 'select',
  inputOptions: [
    { text: 'Choose one...', value: '' },
    { text: 'Choice One', value: '1' },
    { text: 'Choice Two', value: '2' },
    { text: 'Choice Three', value: '3' }
  ],
  callback: function (result) {
    console.log(result);
  }
});

Checkbox input

bootbox.prompt({
  title: 'This is a prompt with a set of checkbox inputs!',
  value: ['1', '3'],
  inputType: 'checkbox',
  inputOptions: [
    { text: 'Choice One', value: '1' },
    { text: 'Choice Two', value: '2' },
    { text: 'Choice Three', value: '3' }
  ],
  callback: function (result) {
    console.log(result);
  }
});

Custom dialogs

Flexible dialogs with custom buttons, sizes, and init hooks.

Buttons and callbacks

bootbox.dialog({
  title: 'A custom dialog with buttons and callbacks',
  message: '<p>This dialog has buttons. Each button has its own callback function.</p>',
  size: 'large',
  buttons: {
    cancel: {
      label: "I'm a cancel button!",
      className: 'btn-danger',
      callback: function () { console.log('Custom cancel clicked'); }
    },
    noclose: {
      label: "I don't close the modal!",
      className: 'btn-warning',
      callback: function () {
        console.log('Custom button clicked');
        return false;
      }
    },
    ok: {
      label: "I'm an OK button!",
      className: 'btn-info',
      callback: function () { console.log('Custom OK clicked'); }
    }
  }
});

Loading overlay

var dialog = bootbox.dialog({
  message: '<p class="text-center mb-0">Please wait while we do something...</p>',
  closeButton: false
});

setTimeout(function () {
  dialog.modal('hide');
}, 2000);
